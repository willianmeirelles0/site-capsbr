# Assets esperados pelo site

Coloque os arquivos abaixo com estes nomes exatos para que o `index.html` já
encontre tudo automaticamente (nenhuma alteração de código necessária):

- `assets/willian-foto.jpg` — foto do fundador usada na seção "Sobre".
- `assets/logo-og.png` — imagem usada quando o link do site é compartilhado
  (WhatsApp, Instagram, etc.), formato recomendado 1200x630px.
- `assets/catalogo/catalogo-capsbr.pdf` — o catálogo em PDF, usado no botão
  "Baixar catálogo em PDF" da seção Catálogo.
- `assets/catalogo/*.jpg` (ou `.png`) — fotos dos produtos do catálogo.
  Ainda não foram incluídas no HTML porque o conteúdo do PDF do catálogo
  precisa ser extraído primeiro (nomes de produto, categorias, imagens).
  Assim que o PDF chegar, os cards placeholder da seção `#catalogo` em
  `index.html` são substituídos pelos produtos reais.

Fontes da marca (Nasalization, Gotham, Codec) não precisam de arquivo aqui
por enquanto: o logo já está embutido como vetor no próprio `index.html`, e
o texto do site usa Montserrat (Google Fonts).
